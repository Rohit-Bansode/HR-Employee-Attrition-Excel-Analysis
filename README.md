## Project Title:  HR-Employee-Attrition-Excel-Analysis

## Project Goal:
Analyzed employee attrition patterns using Advanced Excel (XLOOKUP, Pivot Tables, Dashboard) to identify high-risk departments, roles, and employee segments.

---
## Tools and Technology:

- Microsoft Excel (Pivot Tables, XLOOKUP, VLOOKUP, Slicers, Conditional Formatting, Charts)

---
## Dataset:

- **Source:** [IBM HR Analytics Employee Attrition & Performance](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset)
